# 🏋️‍♂️ FitLog — Workout Library & Routine Planner

FitLog is a high-performance, dark-themed web application built for fitness enthusiasts to discover exercises, structure daily workout plans, and track routines with zero friction.

---

## 📌 About The Project

FitLog provides a sleek, modern interface to browse curated workout routines, inspect step-by-step exercise instructions, and organize training schedules. With real-time metrics tracking and local persistence, users can curate their daily workout plan, save favorites for later, and check off completed lifts seamlessly.

---

## 🛠️ Technologies Used

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://react.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **State & Persistence:** React Context API + Browser `localStorage`

---

## ✨ Key Features

1. **🏋️ Dynamic Workout Library & Detailed Views**  
   Browse workouts with instant visual feedback, filter specs, and step-by-step instructions including targeted muscle groups, duration, calorie burn, difficulty, and user ratings.

2. **📅 Today's Plan & Dynamic Metrics**  
   Add lifts directly to "Today's Plan" with an automated aggregate banner that calculates total exercises, combined duration (minutes), and total estimated calorie burn in real-time.

3. **🔖 Save for Later & Deep Linking**  
   Bookmark routines into a dedicated "Saved" list and switch seamlessly between tabs or navigate via URL parameters directly from the navigation bar counters.

4. **✅ Interactive Routine Completion & Sorting**  
   Mark planned lifts as "Done" with visual completion indicators, remove finished items, and sort lists dynamically by duration, calories, or exercise name.

5. **🔔 Real-Time Badges & Toast Notifications**  
   Instant feedback through animated toast pop-ups when adding, removing, or saving workouts, synchronized live with navigation badge counters.
